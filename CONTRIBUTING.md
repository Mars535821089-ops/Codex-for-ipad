# Contributing

Thanks for helping make Codex for ipad better.

## Before opening a PR

- Keep provider-specific behavior behind an Adapter / Provider boundary.
- Never commit API keys, auth files, Team IDs, device UDIDs, profiles or IPAs.
- Never commit an official DMG, app bundle, `app.asar`, extracted desktop assets or proprietary binaries.
- Preserve iPadOS 18 compatibility and physical-device behavior.
- Add focused tests for behavior changes.
- Run the relevant Swift, Rust and Python tests.

## Good first contributions

- iPad keyboard and pointer polish
- accessibility and localization
- iCloud Drive conflict/status UX
- Provider compatibility
- MCP compatibility
- documentation and reproducible build improvements

Use Issues for bugs and Discussions for broader product ideas.
